# Horizon Jade Lab — DARK (Android)

Standalone, **offline**, original companion to the Horizon launcher and Glass Lab.
This is **not** a reskin of the Glass Lab APK: it is a new app with a completely
independent Android package identity (\`dev.horizon.jadelab\`). It is designed to
test **Old School / Horizon Jade dark only**, not Liquid Glass.

## What it tests

- A full-screen responsive Horizon Jade *mock dashboard* with Play, Mods,
  Packs, Shaders, My Files, Settings and Skins; the preview does **not** install
  or launch Minecraft and never touches the user's worlds/accounts.
- WebGL2 / GLSL ES 3.00 with live gradients, broad energy waves, vignette,
  atmospheric fog, GGX/Schlick material response, specular lights, surface
  bevels, AO, controlled glow, and cursor-driven lighting.
- Real GPU render-scale (0.45–1.0), frame cap (30–120), reduced motion.
  Text is rendered by the native WebView and remains sharp at reduced GPU scale.
- Independent, foldable groups in every tab and the ability to **collapse the
  entire editor, expand it, resize it vertically, or fully hide it** while
  inspecting every pixel of the phone screen in landscape or portrait.
- Edit and save presets locally; export **every individual tab** as JSON;
  export the entire preset as JSON; export one complete ZIP containing
  section JSONs, live shaders, uniform mapping, manifest and shader preview.
- Import JSON tab/preset or a ZIP generated by this app.
- All downloads go into **Downloads/JadeLab/** using Android MediaStore.
  Desktop browser fallbacks download through Blob URLs.

## Build

Requires Android SDK 35, a JDK 17+ and Gradle 8.14.
For a local build, make a disposable test keystore:

\`\`\`bash
mkdir -p experiments/jade-lab/android/.local
keytool -genkeypair -keystore experiments/jade-lab/android/.local/jade-lab-debug.keystore \\
  -storepass android -keypass android -alias jadelabdebug -keyalg RSA -keysize 2048 \\
  -validity 3650 -dname "CN=Jade Lab Temporary Test"
gradle --no-daemon -p experiments/jade-lab/android assembleRelease
\`\`\`

The isolated GitHub Actions job builds and verifies an ARM64-compatible
standalone APK with an ephemeral key. Test APKs signed by **different temporary
keys** require uninstalling the prior *Jade Lab* package before installation.
It does not share the package or data with Horizon or Glass Lab.

## Source architecture

- \`src/main/assets/index.html\`: full-screen console preview and editor shell.
- \`src/main/assets/styles.css\`: responsive sizing, scrollable accordion editor.
- \`src/main/assets/renderer.js\`: real GPU shaders; no framework or network.
- \`src/main/assets/app.js\`: controls, persistence, JSON/ZIP import and export.
- \`JadeLabActivity.java\`: offline WebView host and restricted scoped storage export.

The exported GLSL is the *actual* WebGL2 shader source used in the preview.
Because Horizon uses wgpu/WGSL, the export is **an engineering reference pack**,
not an automatically compatible native Rust/WGSL mod. All values can be
transferred to Horizon's corresponding material uniforms during integration.

## Limits

Device performance and visual appearance require testing on real Android GPUs.
Shader screenshots contain the WebGL layer, not HTML text. Display, UI and
files are completely local; the APK needs no internet or broad storage access.
